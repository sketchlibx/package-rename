ARCHIVE PRESERVATION
Compressed entries stay compressed

Unchanged APK entries keep their original compressed payload. Changed entries are recompressed with the original ZIP compression method.

META-INF is preserved

License/version metadata stays. Only stale APK signing records are removed so the output can be signed cleanly.

Exact-length package swap

pro.sketchware and neo.sketchware have the same byte length, so direct byte replacement is possible without shifting surrounding data.
